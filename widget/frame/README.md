# Содержимое iframe виджета

Здесь живёт сам чат: разметка, стили и логика общения с бэкендом.

* `index.html` — каркас окна;
* `widget.js` — отправка сообщения, приём ответа стримом (SSE),
  кнопка «Продолжить в Telegram» (запрашивает `link_token`);
* стили повторяют экран 03 прототипа.

Отличие от Telegram-канала: источники показываются кликабельными бейджами
`[1] [2]` с подсказкой «документ, страница», а не строкой-футером.

СТАТУС: не реализовано.
