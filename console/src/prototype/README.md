# Разметка экранов из эталона

Вырезано из `soro-business-console-2.html` без правок. Экраны, которые
ещё не стали живыми компонентами, рисуются этой разметкой один в один —
так дизайн совпадает с эталоном с первого дня, а не «когда дойдут руки».

По мере реализации файл заменяется настоящим компонентом: так уже
случилось с экраном 02 «База знаний».
