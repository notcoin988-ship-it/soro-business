# Консоль: структура

Стек зафиксирован ТЗ: React 18 + Vite + TypeScript. Библиотеки сверх
списка — только через явное решение; `qrcode.react` названа в ТЗ прямо
(раздел про экран 05), поэтому она здесь легальна.

**Эталон — `soro-business-console-2.html`.** Правило раздела 9 буквальное:
«повторяй попиксельно, ничего не улучшать от себя». Палитра
`--rose #E8506B`, `--brass #DCA84C`, `--ink #110710`, шрифты
Unbounded / Onest / JetBrains Mono.

| Файл | Экран | Состояние в прототипе |
|---|---|---|
| `screens/Overview.tsx` | 01 Обзор | статика: 4 KPI, чек-лист, тумблеры |
| `screens/Knowledge.tsx` | 02 База знаний | таблица источников, статусы, прогресс |
| `screens/Playground.tsx` | 03 Площадка | **живая**: чат + панель retrieval |
| `screens/Omni.tsx` | 04 Омниканальность | **живая**: 3 устройства, 15 шагов |
| `screens/Channels.tsx` | 05 Каналы | QR на бота, сниппет виджета |
| `screens/Inbox.tsx` | 06 Инбокс | список диалогов, переписка, WebSocket |
| `screens/Analytics.tsx` | 07 Аналитика | донат, бары, топ-темы |

`lib/api.ts` — единственное место, где знают про адреса бэкенда.
`components/` — общее: карточки, бейджи источников, спарклайны.

**Про экран 04.** Он презентационный, бэкенда не имеет: массив `OMNI` из
15 шагов переносится как есть, тайминги обязаны совпасть с прототипом —
350 мс до старта, 1150 мс для системных сообщений, 1500 мс для остальных.
